# 先知小圈信息跟踪

本目录用于持续记录、拆解和复盘“先知”小圈消息，目标不是直接照单买入，而是把消息转化为可验证、可跟踪、可复盘的研究线索。

## 核心方法论

1. **先进圈先复盘，不先追涨**
   - 新消息不等于新机会。
   - 先回看至少近一个月的点评、文件、图片和留言区经验。
   - 重点找出：此前底部提示、持续跟踪逻辑、预期差变化、行业脉络和已兑现程度。

2. **先判断位置，再判断价值**
   - 对新出现的公司，先搜索此前是否已经点评过。
   - 判断公司当前是否已经积累较大涨幅。
   - 没有成本优势或先手优势时，优先等待分歧、调整、回落后的关注机会。

3. **把消息拆成三层**
   - **行业逻辑**：产业趋势是否仍在加强。
   - **公司逻辑**：公司是否绑定核心客户、订单、资源、商业模式或利润兑现路径。
   - **交易逻辑**：当前市场是否已经充分交易，短期是否存在事件情绪发酵。

4. **区分中长期逻辑和短期情绪**
   - 中长期：看产业趋势、供需格局、业绩弹性、商业模式变化。
   - 短期：看财报、招标、调研、股价异动、资金提前布局、事件催化。
   - 不把短期催化误认为长期确定性。

5. **用复盘代替焦虑**
   - 追涨往往来自怕踏空，不一定是技术能力。
   - 更重要的是在市场分歧、恐慌、回调时，基于已验证逻辑分批关注。
   - 所有标的都要记录“原始观点、验证证据、价格位置、后续变化、复盘结论”。

## 文档定位

本文件只维护先知研究体系的 **方法论和判断标准**，包括研究原则、泊松过程、主题分类、作者提示词解释和交易手册。

以下执行性内容统一以 `finance/先知/工作流.md` 为准：

- 聊天导出格式识别与成员昵称脱敏；
- 日总结、文章复盘和月度合并的处理步骤；
- 输出目录、文件命名和更新范围；
- 图片 OCR、公众号 PDF 和图文长文处理；
- 台账、历史关注清单、主题索引和 CSV 校验。

钉钉原始导出统一保留在 `exports/YYYY-MM-DD/先知/`。`finance/先知/` 只承载研究复盘、主题沉淀、台账、索引和历史关注清单。

## 研究边界

- **圈内观点只作为研究线索，不直接等同于事实或投资建议。**
- **钉钉日总结默认不联网搜索，先保留公司、财务、订单、产能、客户绑定等原文关注点和作者提示。**
- **只有用户明确要求查公告或外部资料时，才补充公告、财报、交易所问询回复、机构纪要或主流权威来源；资料只作背景，不改写作者提示。**
- **台账和历史关注清单使用作者提示词与交易表达，不设置“已验证、部分验证、未验证”等状态标签。**
- **已经大涨的标的，应额外记录当前位置、历史涨幅和潜在回撤风险。**

## 交易与复盘规则补充

- **低位多看逻辑变化，高位多看趋势量价。**
- **估值目标只用于建立空间感，不用于机械持有或刻舟求剑。**
- **讲叙事和催化的标的，应按波段机会跟踪；讲订单、利润、产能、毛利率的标的，才进入业绩兑现跟踪。**
- **同一主线内不能只比较 PE，要比较行业生命周期、业绩兑现阶段、市场关注度和资金审美。**
- **强主题中也要分辨先手优势。没有先手时，优先等待分歧和调整，而不是追涨补票。**

## 泊松过程与等待纪律

来源：`finance/投资是泊松过程.pdf`。后续分析股票时，除行业、公司和交易三层拆解外，应增加 **状态跳变概率** 与 **等待质量** 判断。

### 一、核心理解

投资收益并不总是连续发生，很多重要收益来自少数关键事件带来的 **非线性状态跳变**，例如订单爆发、财报超预期、供需反转、客户验证、价格上行、管理层上调指引或市场重新定价。

这里的 `λ` 可理解为 **好事发生的强度**，不是预测明天涨跌，而是判断某只股票或某条主线在未来一段时间内发生 **向上状态迁移** 的概率密度。

### 二、λ 与证据网络

| 维度 | 判断标准 | 操作含义 |
| --- | --- | --- |
| **λ 低** | 催化稀疏，证据长期无更新 | 观察或小仓位，不把“等得久”当作买入理由 |
| **λ 上升** | 客户、订单、收入、利润率、价格、产能、行业趋势等信号开始变密 | 加大研究强度，准备观察仓或等待分歧 |
| **λ 高** | 催化密集，多个独立证据互相印证 | 可能进入重定价窗口，但仍需看价格是否已充分反映 |
| **λ 下降** | 证据斜率转弱，兑现推迟，叙事无法验证 | 重新评估机会成本和退出条件 |

真正有价值的不是单条新闻，而是 **证据网络接近临界密度**：客户在买、收入在加速、利润率未恶化、订单在增长、行业趋势配合，同时股价尚未完全定价。

### 三、高质量等待的条件

高质量等待必须同时满足：

1. **λ 在上升**：不是单纯因为跌多了、估值低或沉寂太久。
2. **证据在变密**：数据、客户、财务、产业链、价格和量价行为能相互确认。
3. **退出条件清晰**：提前定义什么情况说明逻辑错误、状态跳变失败或机会成本过高。
4. **仓位与等待期匹配**：现金不是无效空仓，而是等待高 λ、高赔率、高定价差机会的选择权。

低质量等待通常表现为：没有证据更新、没有反证条件、没有复盘时钟，只是因为成本价、旧逻辑或情绪不愿退出。这类等待应视为 **资本钝化**，不能包装成长期主义。

### 四、用于股票分析的检查问题

分析单只股票或主题时，必须补问：

1. **事件强度**：未来 1-2 个季度是否存在财报、订单、招标、价格、客户认证、政策或产品发布等关键事件。
2. **有效跳变概率**：即使事件发生，它是真正状态迁移，还是短期噪音和主题交易。
3. **赔率结构**：上行空间是否明显大于下行风险，当前价格是否仍有定价差。
4. **等待成本**：资金占用、波动、机会成本和基本面恶化风险是否可承受。
5. **反证条件**：哪些证据出现后必须下修逻辑或退出观察。

简化表达为：

`单位时间可投资期望值 ≈ λ × 有效状态跳变概率 × 赔率 - 等待成本 - 脆弱性成本 - 机会成本 - 假信号成本`

核心纪律：**买的不是股票代码，而是向上状态跳变的可能性；等的不是时间，而是证据网络达到临界密度。**

## 交易手册执行标准

来源：`finance/交易手册.pdf`。后续所有基于圈内消息的操作和建议，都应同时受本节约束。

### 一、仓位与持仓纪律

1. **分仓轻仓**
   - 不满仓单吊一只股票。
   - 分仓的目的不是追求短期爆发，而是降低单一标的风险、保持心态稳定。
   - 稳定盈利优先于短期暴利，市场里 **跑得远比跑得快更重要**。

2. **聚焦核心**
   - 持仓不宜过多，原则上最多不超过 **3 只**。
   - 只聚焦热门板块核心、主线核心或独立逻辑核心。
   - 持股过多会在板块分歧时错过最佳卖点，容易把短线被动做成长线。

3. **计划性交易**
   - 不临盘随意选股。
   - 盘后先复盘：板块是否有持续性、核心是谁、预期是否仍在、适合接分歧还是追一致。
   - 好板块和好个股往往能走出一段趋势，买入不急，也不因怕错过而追涨。

### 二、主线阶段性见顶信号

当主线板块出现以下情况，要进入 **止盈、降仓、清仓观察** 状态：

| 信号 | 含义 | 处理 |
| --- | --- | --- |
| 利好脱敏 | 板块对利好消息不再上涨，说明涨幅可能已充分 | 放弃二波幻想，准备清仓 |
| 龙头跌破 5 日线/10 日线 | 量化资金容易触发集中抛盘 | 先卖出，再观察 |
| 龙头高位大阴线或跌停，次日无强修复 | 板块可能阶段性见顶 | 持有同板块个股应优先止盈止损 |
| 一字情绪龙头封单减弱 | 情绪退潮风险上升 | 先处理 20CM、30CM 等弹性套利品种 |
| 趋势龙头盘中放量滞涨 | 资金可能开始兑现 | 降低仓位，等待重新确认 |

主线退潮后通常进入混沌期，原则上 **不做同板块卡位活口**，优先观察其他方向的流动性核心或独立逻辑核心。

### 三、5 日线与 10 日线纪律

| 场景 | 操作规则 |
| --- | --- |
| 趋势股跌破 5 日线且不能迅速拉回 | 注意减仓 |
| 跌到 10 日线并站稳 | 视情况考虑是否接回 |
| 跌破 10 日线 | 短线纪律上应出清 |
| 长线持仓但破 5 日线 | 也应减仓，不应躺平 |
| 长线持仓重新站回 10 日线 | 可重新评估是否买回 |

核心原则：**10 日线是短线生命线**。在量化资金普遍锚定 5 日线和 10 日线的环境下，破位后不能只靠主观基本面硬扛。

### 四、盘中减仓与清仓纪律

| 盘中情况 | 处理规则 |
| --- | --- |
| 突然深杀 | 通常等反抽，反抽冲不上均线再清仓 |
| 开盘直线下杀、崩溃分时 | 不接，不格局；反抽不上均线清仓 |
| 跌停 | 视为最后清仓纪律点，不能赌侥幸 |
| 竞价大跌或竞价破 5 日线 | 警惕开盘量化抛盘；若未走，等反抽轻仓处理 |
| 龙头高位大阴线或破 5/10 日线 | 同板块个股先止盈止损，不纠结点位 |

三个重要盘中纪律点：

1. **冲高回落破开盘价**
2. **冲高回落破均线**
3. **冲高回落翻绿**

以上都属于减仓或清仓信号。若担心卖飞，应分批处理，而不是完全不动。

### 五、止盈标准

1. **赚钱卖出都是对的**
   - 不把“卖飞”视为错误。
   - 如果后续再买回来，应当视为一次新的短线买点，而不是原交易的延续。

2. **冲高不封板的止盈规则**
   - 主板股票：冲高 **7%-8%** 不快速封板，回落到 **5% 以下**，应考虑减仓或止盈。
   - 创业板股票：冲高 **15% 以上** 后回落到 **10% 左右**，应考虑减仓或止盈。

3. **趋势股加速**
   - 趋势股加速通常更接近卖点，而不是买点。
   - 连板情绪小票一旦爆量减速，要警惕风险。
   - 加速后的高开爆量，多数情况下偏兑现。

4. **跟风中位股**
   - 板块跟风中位股只能按套利处理，不能格局。
   - 卖点要锚定板块核心、龙头走势和行情预判。

### 六、通用交易原则

- **急跌不急卖，但快速跌停除外。**
- **急涨不急买，等企稳后再看。**
- **买卖都应分批，防止一次性买错或卖飞。**
- **做错不能意淫，不能临时找利好欺骗自己。**
- **控制回撤比追求盈利更重要。**
- **市场永远是对的，错的只能先从自己的交易计划和执行纪律里找。**

## 作者提示词与交易表达

作者的交易表达不直接等同于买入或卖出评级。处理历史留言板、群主回复时，只保留原文提示词及其交易含义，不另设正式判断标签。

| 作者提示词 | 交易表达 |
| --- | --- |
| “提示机会”“低位多看逻辑”“低位回复逻辑和基本面的留言我会回复” | 低位关注产业逻辑和基本面，不写成买入评级 |
| “趋势保持留”“高位多看图” | 趋势未破时跟踪量价，不等于长期持有不动 |
| “趋势破位走”“止盈止损”“赚到而不是赚过” | 条件式退出或利润保护，不直接写成卖出指令 |
| “认错的速度”“买入错误，卖出幻想” | 交易纪律和风险表达；“卖出幻想”不是个股卖出信号 |
| “务必不能”“一定要”“最重要的是” | 语气和强调程度，不能单独判断方向 |
| “只是参考，而不是指令”“自己对结果负责” | 免责声明和合规表述 |

**提示词用于描述作者的交易框架，不能直接改写成“强烈买入”或“强烈卖出”评级。**
