# 先进制程封测测试链

## 主题定位

本主题跟踪 **先进制程扩产、先进封装、第三方测试、测试设备、探针耗材、半导体材料和设备零部件** 的景气传导。

先知内容中，这条线的核心不是传统半导体周期修复，而是 **AI 大芯片、国产算力、先进制程和存储扩产共同提高后道测试、封装和材料设备环节的重要性**。

## 2026-03 复盘摘要

3 月最值得沉淀的判断是：**测试链不是低壁垒周期尾部环节，而是先进制程、AI 大芯片和国产算力良率的关键瓶颈**。

随着国产 GPU 回流、先进制程扩产、CoWoS/HBM 等先进封装需求提升，测试时间、测试精度、Pin 脚数量、功耗要求和耗材价值量都可能上升。

## 2026-05 复盘摘要

5 月的核心变化是：**先进制程和测试链从概念扩散进入公告、订单和高位业绩验证阶段**。

月内重点线索包括鼎龙股份 CMP 抛光液公告、韬定律/逻辑折叠、存储扩产、富创精密、珂玛科技、京仪装备、长川科技、精智达、和林微纳、Rubin 探针、靶材涨价和长鑫 IPO。5 月 26 日鼎龙 CMP 抛光液属于相对清晰的公告级进展；韬定律则属于技术叙事和产业推演，必须继续看晶圆厂 CAPEX、设备招标和材料订单。

5 月底科技拥挤度上升后，该主题的判断重点从“是否有产业逻辑”转为“中报、三季报、订单、合同负债和毛利率能否兑现高位预期”。

## 2026-07 复盘摘要

7 月的核心变化是：**半导体扩产和国产替代由涨价与技术叙事，进一步进入招标、交付、验收和收入的产业化验证。** 长鑫扩产、晶圆代工、先进封装、量检测、离子注入、厂务及国产浸没式DUV均反复出现；其中设备生产、客户采购、工艺验证、稳定运行和复购必须分阶段记录。

存储扩产可提高设备材料链的研究优先级，但DRAM价格、产能周期和上市公司估值需要独立判断。国产浸没式DUV及其配套环节处于高事件强度、低业绩可见度阶段，先核主机、客户和工艺闭环，再看供应商订单与收入传导。

## 核心逻辑链

1. AI 大芯片、国产 GPU 和先进制程项目增加。
2. 芯片面积、功耗、复杂度和封装形态提升。
3. 测试时间、测试设备精度、探针和分选耗材价值量上升。
4. 第三方测试、测试设备、先进封装和材料零部件环节受益。
5. 最终需要通过订单、产能利用率、毛利率和财报验证。

## 重点方向与标的

| 环节 | 代表标的/方向 | 关注点 |
| --- | --- | --- |
| 第三方测试 | 伟测科技、利扬芯片 | 国产 GPU 回流、测试外包、产能利用率 |
| 测试设备 | 长川科技、精智达 | AI 芯片测试复杂度提升、设备 ASP |
| 分选/探针/耗材 | 金海通、和林微纳、强一股份、矽电股份 | 测试时长、Pin 脚、功率和精度要求 |
| 先进封装 | 盛合晶微、甬矽电子、长电科技、通富微电 | CoWoS、HBM、国产算力封装需求 |
| 半导体材料 | 鼎龙股份、江丰电子、欧莱新材 | 抛光垫、抛光液、靶材和国产替代 |
| 设备零部件 | 富创精密、京仪装备、珂玛科技、骄成超声 | 存储扩产、先进逻辑扩产、国产设备链订单 |
| 韬定律/逻辑折叠 | 先进制程设备材料链、先进封装链 | 前道扩产、CMP、沉积、清洗、量检测和封装步骤是否增加 |
| Rubin 探针 | 和林微纳、强一股份 | Rubin 量产节奏、探针交期、价格和客户导入 |
| 存储扩产/长鑫 IPO | 长鑫、长存、设备材料链 | 扩产订单、IPO 抽水、存储设备材料业绩兑现 |

## 关键验证问题

- 伟测、利扬、长川、精智达、金海通等是否在 Q1/Q2 体现测试链量价通胀。
- 鼎龙股份、江丰电子、洁美科技、富创精密、京仪装备等能否用财报验证设备材料景气。
- 国产 GPU、先进逻辑和存储扩产是否形成明确的封测、测试和材料订单。
- 先进封装相关收入是否从概念进入实际确认。
- 鼎龙 CMP 抛光液公告中的客户、订单金额、收入确认和利润弹性是否能在后续财报体现。
- 韬定律是否真实带动前道先进制程扩产、先进封装工艺步骤增加和材料耗材用量提升。
- 长川科技、精智达、和林微纳等是否在 AI 测试、存储测试和 Rubin 探针方向形成订单。
- 长鑫 IPO 是否强化存储扩产订单，还是先造成高位半导体链流动性抽水。

## 风险与反证

- 半导体设备材料和封测链条订单确认周期长，题材可能领先业绩较多。
- 如果先进制程扩产节奏低于预期，测试和封测需求会后移。
- 测试链公司需要区分国产算力增量和传统消费电子周期修复。
- 个别标的若只靠客户传闻而无公告或财报验证，应降低权重。
- 技术叙事不能直接外推为订单，韬定律、逻辑折叠和先进封装都需要设备材料订单验证。
- 高位设备材料标的若中报只是符合预期，可能无法继续支撑估值扩张。
- 探针、靶材和零部件涨价口径需区分海外供需、现货价格和上市公司实际 ASP。
