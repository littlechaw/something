# AI Agent 与 Token 基础设施

## 主题定位

本主题跟踪 **AI Agent 普及、Token 调用量增长、云服务涨价、数据与运维基础设施扩容** 之间的传导关系。

先知内容中，这条线不是单纯的应用题材，而是围绕 Agent 使用频率提升后，对算力、存储、数据库、调用链监控、边缘网络和安全合规提出的新需求。

## 2026-03 复盘摘要

3 月的核心变化是：**Agent 风险讨论没有证伪 Agent 普及趋势，反而强化了 Token 消耗、调用链复杂度和云资源需求增长的观察框架**。

阿里云 AI 算力和存储涨价被视为重要验证信号，说明 Token 调用量、模型推理和存储需求可能已经开始向云厂价格体系传导。

## 2026-05 复盘摘要

5 月的核心变化是：**Token 基础设施从“调用量增长”升级为“Token 工厂、TaaS 和模型服务分成”的商业模式验证**。

润建股份、五象云谷、字节 Seedance/Skylark、火山引擎、Amazon Bedrock、Anthropic 等线索贯穿全月。5 月不再只讨论 Agent 会消耗多少 Token，而是进一步追问：谁掌握模型服务入口，谁承担算力和电力成本，谁按 Token 分成，收入如何确认，模型降价后调用量能否放大。

5 月 25 日 AI Agent 长文还提供了风险框架：如果企业 AI 进入生产流程，硬件和 Token 基础设施需求会更强；如果仍处于高采用低转化，则 AI 泡沫和企业 ROI 压力会加大。这个框架应与 Token 工厂利润测算一起使用，不能只看单一模型上线。

## 核心逻辑链

1. Agent 从单次问答走向多轮任务执行。
2. 每次任务会产生更多模型调用、工具调用、检索和上下文存储。
3. Token 消耗、向量化、日志追踪和推理资源需求上升。
4. 云厂 AI 算力、存储、数据库、网络和监控资源承压。
5. 若价格上涨和收入确认持续出现，基础设施公司进入业绩验证阶段。

## 重点方向与标的

| 方向 | 代表线索 | 关注点 |
| --- | --- | --- |
| 云涨价 | 阿里云 AI 算力和存储涨价 | 其他云厂是否跟进，涨价能否传导到收入和利润 |
| 向量数据库 | 星环科技、海量数据 | Agent 长期记忆、低延迟检索、实时向量化需求 |
| 智能 APM | 博睿数据 | Agent 调用链追踪、预算感知、成本控制 |
| 边缘计算/CDN | 网宿科技 | 高频调用下的低延迟网络和边缘推理需求 |
| 安全合规 | 云安全、网安、沙箱隔离相关方向 | Agent 权限、数据安全和合规治理 |
| Token 工厂 | 润建股份、五象云谷、字节/火山引擎 | 模型部署、Token 单价、调用量、分成比例、收入确认 |
| 海外 TaaS | AWS Bedrock、Anthropic | Token-as-a-Service 利润率、收入锁定性、需求风险 |

## 关键验证问题

- 阿里云涨价后，其他云厂是否跟进 AI 算力、存储或 MaaS 价格调整。
- MaaS、API 调用量、推理服务收入是否能在财报或经营数据中体现。
- 向量数据库、APM、CDN 公司是否披露 AI 客户、订单或收入增量。
- Agent 安全风险是否只是短期情绪冲击，还是会影响企业侧部署节奏。
- 润建五象云谷是否正式部署 Seedance/Skylark 等闭源模型，并对外提供 Token 服务。
- Token 工厂的合作方、分成比例、调用量、Token 单价和收入确认方式是否有公告、合同或财报证据。
- AWS Bedrock/Anthropic 的 TaaS 利润率和收入分成机制是否能由正式披露或权威研究验证，是否可映射到国内。
- AI Agent 企业 ROI 是否从试点转入生产，能否支撑硬件、云服务和 Token 基础设施估值。

## 风险与反证

- 产品热度不等于收入闭环，应用侧爆发可能无法传导到相关上市公司。
- 云涨价如果只是结构性调价，而非供需紧张，基本面含义会下降。
- Agent 安全、权限和合规问题可能拖慢企业部署。
- 软件基础设施公司估值弹性高，但收入确认通常慢于题材发酵。
- Token 工厂若只披露合作意向，没有调用量、定价和收入确认，不能直接按高利润模式估值。
- 模型 API 降价既可能扩大调用，也可能压缩单位收入和分成利润。
- 海外 TaaS 样本不能直接外推到国内，国内模型能力、卡源、客户付费和监管环境不同。
