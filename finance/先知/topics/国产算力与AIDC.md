# 国产算力与 AIDC

## 主题定位

本主题跟踪 **国产 AI 算力、AIDC、算力租赁、超节点互联、昇腾链、液冷、边缘云和数据中心安全** 的长期变化。

先知内容中，这条线是 2026 年 3 月最核心主线，重点已经从“缺卡”和“国产替代”扩展到 **国产算力系统化建设**。

## 2026-03 复盘摘要

3 月的核心变化是：**国产算力不再只是芯片或服务器题材，而是向超节点互联、交换芯片、连接器、AIDC、液冷和边缘网络扩散**。

复盘中最重要的判断是：国产超节点的增量不只在芯片，更在通信互联和系统工程。AIDC 与算力租赁则是需求落地和价格验证的重要观察窗口。

## 2026-05 复盘摘要

5 月的核心变化是：**国产算力生态从芯片替代扩展到 AIDC、Token 工厂、昇腾总代、液冷 I/O、PCIe/CXL Switch、交换芯片和测试链**。

月初围绕华为 AI 芯片替代、DeepSeek 适配、字节国产 AI 芯片采购和算力缺口展开；月中继续讨论 H200/5090 扰动、昇腾总经销、神州数码和深圳华强；月末进一步扩展到意华股份液冷 CAGE、万通发展/数渡科技 PCIe 5.0 Switch、盛科通信、飞荣达散热和字节 CAPEX 上调。

5 月的处理重点是把“国产算力”拆成系统工程：芯片、封装、整机、互联、连接器、液冷、AIDC、Token 服务和渠道分销各自有不同验证口径，不能只靠一个昇腾标签统一估值。

## 2026-07 复盘摘要

7 月的核心变化是：**国产算力从远期扩容叙事进入系统工程与季度兑现的双重验牌期。** 模型自研芯片、昇腾与超节点互联、连接器、交换芯片、液冷、AIDC和Token服务均有新增线索，但高位科技去杠杆和海外高端卡合规扰动要求分别验证卡源、客户、订单、上架率和现金流。

月内对国产算力的有效拆分是：芯片与模型看技术路线、流片和部署；超节点看客户认证、招标与出货；AIDC看机房、上架率、合同和能耗；Token服务看合作主体、计费、分成和收入确认。H200许可和海外拿卡路径只能作为供给变量，实际数量、交付与公司合同才决定业绩影响。

## 核心逻辑链

1. Token 调用量和 AI 应用增长带动算力需求。
2. 海外高端 GPU 供给和政策存在不确定性，国产算力替代需求提升。
3. 国产算力从单卡走向集群和超节点，网络、连接器、液冷、交换芯片价值量提升。
4. AIDC、算力租赁和边缘云成为算力供需紧张的外部验证场景。
5. 最终需要通过客户合同、机柜交付、租赁价格、订单和收入确认验证。

## 重点方向与标的

| 细分方向 | 代表线索 | 关注点 |
| --- | --- | --- |
| AIDC/算力租赁 | 科华数据、利通电子、东方国信、森远股份、奥瑞德 | 客户合同、机柜交付、算力租赁价格、收入确认 |
| 昇腾链 | 华丰科技、意华股份、申菱环境 | 昇腾订单、超节点价值量、液冷供应份额 |
| 交换芯片 | 盛科通信 | 大厂 scale out/scale up 导入、客户认证、订单 |
| 连接器 | 华丰科技、意华股份、航天电器 | 950 线模组、224G 背板连接器、小批量和规模供货 |
| 边缘云/CDN | 网宿科技 | AI 边缘计算收入、云厂合作、价格传导 |
| 昇腾总代/分销 | 深圳华强、神州数码 | 华为授权名单、板卡/整机分销范围、库存资金占用、毛利率 |
| PCIe/CXL 高速互联 | 万通发展、数渡科技 | 104 通道量产、144 通道投片、客户导入、收入目标 |
| 液冷 CAGE/散热 | 意华股份、鼎通科技、奕东电子、飞荣达 | 审厂、送样、出货、份额、顺价和毛利率 |

## 关键验证问题

- 国产超节点连接器、交换芯片是否出现明确订单和客户导入。
- AIDC 公司是否披露真实客户合同、机柜交付、租赁价格和收入确认。
- 昇腾链订单是否能从供应商口径走向公告、财报或产业链验证。
- AI 边缘计算和 CDN 需求是否能体现到网宿科技等公司的收入结构。
- 深圳华强、神州数码是否正式获得昇腾总经销或计算部件分销授权，授权范围和收入分项如何。
- 意华股份液冷 CAGE 是否正式进入华为昇腾体系，单价、份额、订单和毛利率如何。
- 数渡科技 PCIe 5.0/6.0、CXL 产品是否持续量产并进入 AI 超节点客户。
- 字节 CAPEX 上调是否转化为 AIDC、国产算力、算力租赁或 Token 工厂订单。

## 风险与反证

- H200、国产卡政策和供给变化可能改变国产算力交易节奏。
- AIDC 订单不透明，容易出现合同、框架协议和收入确认混淆。
- 超节点互联技术路线仍需验证，连接器和交换芯片价值量不能只靠推演。
- 高位标的若只靠长期逻辑支撑，仍需遵守趋势和估值纪律。
- 分销模式收入规模可能大，但毛利率和库存资金风险也高，不能把总代资格直接等同高利润。
- 液冷 CAGE、PCIe Switch 和交换芯片从送样、审厂到批量订单仍有验证周期。
- 长鑫 IPO、科技拥挤和高位成交集中可能造成国产算力链内部资金分流。
