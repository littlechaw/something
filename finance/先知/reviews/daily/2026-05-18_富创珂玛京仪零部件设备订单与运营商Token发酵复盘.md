# 2026-05-18 富创珂玛京仪零部件设备订单与运营商 Token 发酵复盘

5 月 18 日的核心结论是：**当天主线集中在半导体设备零部件三家公司深度跟踪：富创精密看产能前置和海外订单，珂玛科技看存储耗材和陶瓷加热器，京仪装备看 Chiller 设备订单和真空泵第二曲线；尾盘补充润建作为三大运营商数据中心建设运维铲子股的 Token 聚合运营商发酵。**

## 基本信息

- 日期：2026-05-18
- 主题：富创精密、珂玛科技、京仪装备、半导体设备零部件、存储扩产、Token 聚合运营商、润建股份
- 涉及行业：半导体设备零部件、先进制程、存储扩产、Token 工厂、运营商数据中心
- 当前状态：待验证

## 一句话结论

当天把半导体零部件主线从板块框架落到具体公司：**富创精密验证“产能前置+海外订单+毛利修复”，珂玛科技验证“陶瓷加热器+存储耗材”，京仪装备验证“Chiller 订单+真空泵期权”，同时润建新增三大运营商数据中心运维和 Token 聚合运营商映射。**

## 核心观点

1. **富创精密被定位为半导体设备零部件龙头。**
   - 原文称 2025 年是利润最差一年，前置产能、研发和人才投入集中进入损益表。
   - 2026 年国内产能已全部投完，折旧见顶、毛利率见底，新产能释放有望摊薄固定成本。
   - 一季度收入同比增长 37%，净利润同比增长 362%，毛利率修复至 27%。
   - 海外客户 AMAT、LAM 被称开始大批量下单，订单从去年 12 月起同比快速增长。

2. **珂玛科技被定位为存储耗材第一股。**
   - 原文称陶瓷加热器成为长存流片瓶颈，两存库存告急加速国产导入。
   - 2024 年首款陶瓷加热器导入长存 fab 1，2026 年保守预期四倍放量，2027 年继续翻倍。
   - 拓荆需求、两存存量需求和短期急单均属于高敏感订单口径，需严格验证。

3. **京仪装备具备设备和零部件双重弹性。**
   - 原文称 Q1 新接订单高增，先进逻辑客户为主；温控设备在两存、先进逻辑客户接近独供。
   - 真空泵新品已在北京三大逻辑客户验证，后续对接存储客户，2027 年有望批量兑现。
   - 关键是订单规模、客户结构、真空泵验证和收入确认。

4. **运营商 Token 聚合发酵，润建被放入铲子股框架。**
   - 原文称下午发酵 Token 聚合运营商，润建股份又是三大运营商数据中心建设运维的铲子股。
   - 该线索和 5 月 19 的 Token 商业模式专题相连，但运营商 Token 聚合和润建实际收入关系仍待验证。

## 主线拆解

### 主线一：设备零部件产能和订单

#### 行业逻辑

先进制程和存储扩产会先带动设备订单，再传导到上游零部件。零部件释放产能周期长，若需求加速，提前扩产的公司有交付壁垒和规模效应。

#### 公司逻辑

富创精密看固定资产前置、海外客户和毛利率修复；珂玛科技看陶瓷加热器、存储客户和耗材复购；京仪装备看 Chiller 订单、存储和先进逻辑客户、真空泵验证。

#### 交易逻辑

三家公司都进入高关注阶段，远期市值目标不能机械使用。后续应看 Q2-Q4 订单、合同负债、发出商品、毛利率和中报预告。

### 主线二：运营商 Token 聚合

#### 行业逻辑

Token 工厂之后，市场开始讨论 Token 运营和运营商聚合。运营商拥有客户、网络和数据中心资源，但商业模式要看分成、客户、模型服务和结算方式。

#### 公司逻辑

润建股份作为三大运营商数据中心建设运维服务商，可以被纳入“铲子股”观察，但不能直接推导 Token 聚合收入，需要合同和收入确认。

## 待验证问题

1. 富创精密 Q1 收入、净利、毛利率修复和固定资产数据是否与财报一致。
2. 富创 AMAT、LAM 海外订单从 2025 年 12 月起连续 50%+增长是否有证据。
3. 珂玛科技陶瓷加热器是否成为长存流片瓶颈，两存库存告急是否属实。
4. 拓荆对珂玛的短期急单、未来需求颗数和四倍放量是否可验证。
5. 京仪装备 Q1 新接订单、先进逻辑客户和存储订单节奏是否可由公告或调研验证。
6. 京仪真空泵在北京逻辑客户和存储客户的验证进度。
7. Token 聚合运营商是否有明确商业模式、参与主体和收入确认。
8. 润建在三大运营商数据中心建设运维中的订单、利润率和与 Token 业务的关系。

## 风险提示与通俗解释

- **订单传闻风险**：客户名和订单增速都需要公告、财报或可靠纪要验证。
- **产能利用率风险**：固定资产多不等于利润高，如果订单不够，折旧会拖累利润。
- **耗材测算风险**：陶瓷加热器市场空间和利润测算假设多，需看真实采购。
- **运营商 Token 概念风险**：运营商参与不等于上市公司收入，不能只按概念外推。
- **高位趋势风险**：零部件龙头新高后，验证不及预期会引发估值回撤。

## 当前处理结论

本日归档为**富创珂玛京仪零部件设备订单与运营商 Token 发酵复盘**。5 月 18 日承接 5 月 15 日零部件历史性机遇框架，把富创、珂玛、京仪三家公司验证点具体化，并为 5 月 19 的 Token 三模式专题埋下运营商 Token 运营线索。
