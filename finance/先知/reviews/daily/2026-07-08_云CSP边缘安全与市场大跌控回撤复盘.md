## 核心观点

1. **云 CSP 的变化集中在增长、利润率和收入结构。** 作者把阿里云 Preview 中的云业务增速、利润率改善、高毛利 MaaS 占比提升和平头哥自研芯片驱动，作为云厂 AI 商业化的核心线索。
2. **开源模型经济可能强化 CSP 受益位置。** 作者认为 GLM、DeepSeek、Kimi、MiniMax 等优质开源模型会提升开源模型收入占比，而云厂可能通过模型托管、推理、API 调用和企业部署受益。
3. **FDE 是模型和 Agent 落地企业流程的组织抓手。** 原文提到 AWS 和 Azure 总计 35 亿美元的 FDE 组织和人才投入，认为这会把客户 Infra 架构导向自有云服务。
4. **国产桌面智能体被放进 CSP 数据和业务飞轮。** 腾讯 workbuddy、阿里 Qoderwork 被作者放在替代 Codex、Claude Code 的框架里理解，核心是带动 AI 应用和 token 收入，同时用高质量数据反哺自有模型。
5. **边缘 CDN 和云安全厂商有新的重估入口。** Cloudflare Monetization Gateway 被作者定义为 agent-first Internet 的基础设施变化，映射到 Cloudflare、Akamai、国内 CSP、网宿、UCloud、七牛等边缘网络和云安全厂商。
6. **交易重心从进攻转为防守。** 晚间两条文字都在强调防风险、控回撤、跌破 10 日线止盈止损、退潮期管住手，核心是不要把 6 月赚钱效应线性外推。

## 主线一：云 CSP、MaaS 与边缘安全

### 行业逻辑

- **MaaS 利润率**：作者认为阿里云 Preview 再次确认 MaaS 业务 margin，云业务增长和利润率改善来自高毛利 MaaS 占比提升以及自研芯片驱动。
- **开源模型经济**：随着 GLM、DeepSeek、Kimi、MiniMax 等开源模型推进，开源模型收入占比提升，CSP 云业务可能成为核心受益者。
- **FDE 落地**：AWS 和 Azure 的 FDE 投入被理解为释放模型和 Agent 行业落地红利，并把客户基础设施导向自有云服务。
- **国产桌面智能体**：腾讯 workbuddy、阿里 Qoderwork 被放在企业级 AI 工作流入口和 token 收入增长框架下。
- **边缘安全与变现网关**：Cloudflare Monetization Gateway 让网页、数据集、API 等数字资源具备收费入口，边缘 CDN/云安全厂商的重要性提升。

### 交易理解

这条主线属于产业框架更新，重点不是单一公司短期涨跌，而是云厂 AI 商业化从算力、模型服务、企业落地到边缘分发的链条变长。当天成员提到“网宿科技今日涨停，有啥原因么”，放在原文逻辑里看，网宿对应的是**边缘 CDN、云安全、Agent 分发和低延迟节点**这一环。
