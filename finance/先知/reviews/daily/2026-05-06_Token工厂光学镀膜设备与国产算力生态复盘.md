## 核心观点

1. **润建股份被定义为 Token 工厂代表。**
   - 电话会议纪要称，公司算力业务将从简单 IDC/算租切到 Token 工厂，即在自有或合作 AIDC 中部署模型，通过 API Token 调用分成。
   - 原文称五象云谷一期投产，二期电力容量约 360MW，是一期 10 倍；并提到资产池、担保授信、发债等约 300 亿元资金规模。
   - 该线索后续必须核验合同、客户、分成比例、Token 单价、调用量、收入确认、能评和融资成本。

2. **茂莱光学从半导体光学扩展到 AI 光互连。**
   - 原文和图片强调 2026Q1 新增订单、累计在手订单、半导体客户占比、北美客户、前道量检测、光刻机物镜、FSO、OCS、CPO 和 AR/VR 检测。
   - 图片中还特别提示，“2 亿美元订单”更像未来一两年的 Sales Opportunity，而非已签订单，这一点应保留为风险提示。
   - 茂莱逻辑强在精密光学平台和客户验证，但订单、收入确认、产能爬坡和光通信收入占比仍需验证。

3. **汇成真空被强化为光刻、光通信和 TGV 多线设备公司。**
   - 原文称传统业务有望修复，苹果链、复合集流体、汽车、光伏等在手订单支撑基本盘。
   - 新兴业务包括光刻机高端镀膜设备、光通信滤光片/FAU/晶圆级镀膜设备，以及 TGV 玻璃基板深孔镀膜。
   - 核心问题不是市场空间，而是客户名单、设备台数、交付验收、收入确认和毛利率。

4. **通富微电被放入 AMD CPU/GPU 和先进封装链。**
   - 作者回复称，通富微电封测大客户是 AMD，GPU 和 CPU 都做；CPU 涨价背景下，通富比普通映射更贴近海外高端 CPU 产业链。
   - OCR 图片补充了 AMD 数据中心收入、服务器 CPU 增长、AI 支出和内存短缺等背景。
   - 但通富受益程度仍要回到 AMD 订单、封测产能、产品结构和利润率。

5. **国产算力生态闭环继续增强。**
   - 作者称“大基金打通国产算力，用国产设备生产国产芯片适配国产大模型然后向全世界输出便宜好用的 Token”。
   - 图片补充 DeepSeek 潜在融资、大基金领投、估值和昇腾推理优化等线索。
   - 这是一个产业链闭环叙事：国产设备材料 -> 国产芯片 -> 国产大模型 -> Token 服务出海，但每一环都需要独立验证。

6. **氦气供应扰动出现止盈提醒。**
   - 作者提示卡塔尔氦气大概要恢复供应，注意氦气逐步止盈。
   - 这类消息属于供给扰动交易，若供应恢复，前期因缺货上涨的工业气体线索可能降温。

7. **方法论消息继续强调复盘和位置。**
   - 成员经验分享强调低位看逻辑变化，高位看图和量价，普通投资者精选 3-5 只即可。
   - 这与目录 README 和交易手册一致，应作为后续高位科技处理纪律。

## 主线拆解

### 主线一：润建股份 Token 工厂

#### 行业逻辑

AI 应用从训练走向推理后，Token 调用量成为算力需求的关键变量。传统算租按时长和设备出租，Token 工厂则试图通过模型部署、推理优化、API 调用和收入分成获取更高毛利。

#### 公司逻辑

| 维度 | 原文口径 | 需要验证 |
| --- | --- | --- |
| 模式 | 从算租转向 Token 工厂，预计获得 Token 收入分成。 | 合同、合作方、分成比例、收入确认方式。 |
| 项目 | 五象云谷一期投产，二期 360MW。 | 项目备案、能评环评、开工和投产节点。 |
| 资金 | 资产池、授信、发债约 300 亿元。 | 授信公告、债券文件、融资成本和资产负债压力。 |
| 盈利 | Token 工厂盈利能力高于传统算租。 | 利用率、单价、模型降价、客户付费和折旧。 |

#### 交易逻辑

润建属于 **模式验证 + 高弹性预期差**。在低位阶段容易被重估，但后续一旦大涨，必须切到客户、合同、财报和 5/10 日线纪律。

### 主线二：茂莱光学半导体光学与 AI 光互连

#### 行业逻辑

AI 基础设施对前道量检测、光刻光学、CPO/OCS/FSO、光学模组和检测设备的需求提升。茂莱被视为“精密光学铲子股”，同时享受半导体国产替代和 AI 光互连升级。

#### 公司逻辑

茂莱的核心验证链条是：

1. 半导体订单是否持续增长。
2. 北美客户和国内客户订单是否能确认。
3. 光通信业务是机会池、样品、订单还是收入。
4. 产能扩张能否按时投产。
5. 毛利率是否在扩产和客户结构变化中维持。

#### 交易逻辑

茂莱的远期空间叙事较强，但图片中的 500 亿市值测算和 2 亿美元潜在需求不能当作确定收益。高位阶段重点看趋势量价、订单兑现和询价/扩产扰动。

### 主线三：汇成真空光刻、光通信和 TGV 设备

#### 行业逻辑

高端真空镀膜设备是光刻机光学、光通信滤光片、晶圆级光学镀膜和玻璃基板 TGV 的共性设备环节。AI 和国产替代共同提升国产设备验证价值。

#### 公司逻辑

| 业务线 | 原文口径 | 验证重点 |
| --- | --- | --- |
| 传统主业 | 苹果链和多领域订单有望集中验收。 | 客户验收、收入确认、毛利率修复。 |
| 光刻设备 | DUV/EUV/离子束镀膜、修复和抛光设备矩阵。 | 客户、台数、招投标、设备交付。 |
| 光通信 | 滤光片、FAU、晶圆级镀膜设备。 | 光器件客户、光芯片客户、订单和验收。 |
| TGV | 深孔镀膜，已交付两条产线口径。 | 客户名称、产线验收、后续批量订单。 |

#### 交易逻辑

汇成的弹性来自多线并行，但多线也意味着验证复杂。后续应按设备台数和验收节奏跟踪，而不是用远期市场空间替代证据。

### 主线四：AMD CPU/GPU 封测与通富微电

#### 行业逻辑

AI 服务器不仅需要 GPU，也需要服务器 CPU、内存和先进封装。AMD 数据中心增长和 CPU 需求上行，会带动其封测供应链关注度。

#### 公司逻辑

通富微电逻辑在于 AMD 大客户绑定和 CPU/GPU 封测业务，但需要验证 AMD 订单增量是否传导到通富营收、毛利率和产能利用率。

#### 交易逻辑

通富比普通 CPU 涨价映射更有产业链相关性，但它仍是周期和客户驱动型公司，不能只靠海外 AMD 股价或 CPU 涨价交易。

### 主线五：国产算力生态闭环

#### 行业逻辑

“国产设备生产国产芯片，适配国产大模型，再输出 Token”的叙事，实质是把半导体设备材料、国产 AI 芯片、模型公司、AIDC 和 Token 服务串成一条自主可控闭环。

#### 公司逻辑

这条链上每一环都需拆开验证：

- 设备材料：能否支持先进制程和先进封装扩产。
- 芯片：昇腾等国产卡出货、性能、生态和供给。
- 模型：DeepSeek 等模型是否与国产芯片适配并商业化。
- AIDC：项目、能耗、客户和上架率。
- Token 服务：价格、调用量、分成和收入确认。

#### 交易逻辑

闭环叙事空间大，但也最容易过度外推。后续以“证据网络是否变密”为核心，而不是靠单一截图或融资传闻。

## 待验证问题

1. **润建股份 Token 工厂**是否有正式合作方、模型部署、Token 分成比例、客户合同和收入确认方式。
2. **五象云谷二期 360MW**是否有备案、能评、开工和投产计划。
3. **茂莱光学 2026Q1 订单和北美客户**是否能被公告或投资者关系资料支持，光通信收入是否开始放量。
4. **茂莱“2 亿美元机会”**到底是潜在销售机会、客户需求池还是已签订单。
5. **汇成真空光刻/光通信/TGV 设备**是否形成明确客户订单、设备台数、验收和收入确认。
6. **通富微电 AMD CPU/GPU 封测**是否随着 AMD 数据中心业务增长形成收入和利润弹性。
7. **DeepSeek 融资、大基金领投和腾讯参与**是否最终落地，估值和资金用途是否清晰。
8. **DeepSeek 与昇腾适配**是否推动国产卡订单，而不只是技术宣传。
9. **NVIDIA 与康宁光连接合作**是否能映射到国内光通信设备、光学材料或镀膜设备订单。
10. **卡塔尔氦气供应恢复**是否带来氦气价格回落，相关标的是否需要按事件结束处理。

## 风险提示与通俗解释

- **模式验证风险**：Token 工厂听起来比算租高级，但如果没有稳定客户、调用量和收入确认，利润只是测算。
- **客户传闻风险**：茂莱、汇成等线索涉及北美客户、苹果链、光通信客户和光刻机客户，未公告前都只能当待验证线索。
- **远期市值测算风险**：500 亿市值、远期收入和净利率假设只能提供空间感，不能作为持有纪律。
- **多线并行风险**：公司同时讲很多新业务，容易提高估值，但也可能因为交付、验收和产能不足导致兑现慢。
- **高位交易风险**：一旦标的已有明显涨幅，必须从逻辑判断切换到 5 日线、10 日线、成交和公告验证。
- **地缘反转风险**：氦气、油价等事件驱动一旦出现供应恢复或谈判缓和，交易逻辑可能快速降温。
