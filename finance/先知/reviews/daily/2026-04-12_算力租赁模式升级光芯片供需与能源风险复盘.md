# 2026-04-12 算力租赁模式升级光芯片供需与能源风险复盘

4 月 12 日的核心结论是：**算力租赁从“拿卡租卡”升级为业绩兑现和 Token 分成预期，光芯片供不应求形成并行主线，霍尔木兹与光伏设备出口扰动仍作为风险线索存在。**

## 基本信息

- 日期：2026-04-12
- 主题：算力租赁、Token 分成、光芯片供需、正泰电源、新莱应材辨析、霍尔木兹风险
- 涉及行业：AI 算力、云服务、光通信、光伏逆变器、半导体设备零部件、能源航运
- 当前状态：待验证

## 一句话结论

当天最重要的增量是**算力租赁商业模式重估**：需求来自 Token 调用量和模型公司算力缺口，供给受高端卡、组网、资金和交付能力约束，作者认为头部公司可能从固定租金走向模型服务或 Token 分成。

## 核心观点

1. **协创数据被超微事件牵连，但作者认为市场已开始脱敏。**
   - 外媒截图中 Sharetronic 被翻译为共享电子数据技术有限公司，涉及高端 Nvidia 芯片服务器备案，导致协创数据被量化资金再次杀跌。
   - 作者认为头部算力租赁公司的渠道多元化，超微事件会提高拿卡成本和合规风险，但不必然否定行业需求。

2. **算力租赁进入业绩兑现和模式升级窗口。**
   - 需求端来自 DeepSeek、智谱等模型缺算力、AI Agent 带来 Token 消耗激增，以及国内云厂 CAPEX 相对不足。
   - 供给端的核心壁垒包括稳定拿卡、万卡集群组网调优、5 个月交期和资金周转。
   - 作者提出新预期差：算力租赁公司可能从裸算力出租升级为模型服务或 Token 分成，估值框架从 PE 向 PS 切换。

3. **光芯片供需紧张继续强化。**
   - 文本和图片均引用 Lumentum 订单排至 2027/2028 的线索，指向海外 CSP 光学组件需求加速。
   - 作者认为 EML、CW 光源和高功率 CW 在 CPO、NPO、Scale-up 光互联中仍有供需缺口，国内厂商存在导入机会。

4. **正泰电源受韩国光伏计划刺激，但需防能源避险资金回流科技成长。**
   - 韩国提出 2030 年可再生能源和光伏新增目标，作者认为正泰电源韩国逆变器份额、美国工商业光伏和海外大储是观察点。
   - 同时提示美伊事件若缓和，能源替代方向的避险资金可能回流科技成长。

5. **新莱应材被归为偏概念映射而非当前高确定主线。**
   - 作者认为其半导体更多是厂务设备和真空零部件早期切入，主业仍受医药、食品厂房下滑拖累。
   - 液冷 CDU 也有更纯粹标的，短期更像量化纳入新凯来概念的交易。

## 主题主线拆解

### 主线一：算力租赁模式升级

#### 行业逻辑

AI Agent、多模态和 Coding 场景会显著放大 Token 消耗，国内模型公司和二线云厂对高端算力的需求大于可获得供给。算力租赁成为海外高端卡受限、国产算力量不足期间的短中期解法。

#### 公司逻辑

宏景科技、协创数据、利通电子、盈峰环境被列为核心标的。作者关注拿卡能力、交付速度、融资能力、客户绑定和是否能获得 Token 分成。

#### 交易逻辑

主线已从低位逻辑进入趋势强化阶段。作者强调低位看逻辑，高位看图和趋势，涨幅过大后应重视波动和止盈纪律。

### 主线二：光芯片和光通信上游

#### 行业逻辑

海外 CSP 光学组件需求加速，Lumentum 产能排期紧张，意味着光芯片、光模块设备和上游扩产链条仍处景气扩散期。

#### 公司逻辑

源杰科技、永鼎股份、东山精密、卓胜微等被提及。卓胜微更多是硅光代工叙事，正式订单可能偏远期，不能直接等同已兑现。

#### 交易逻辑

光通信进入抱团加速段，适合先手持有者按趋势管理；无先手追高风险上升。

### 主线三：能源和政策扰动

#### 行业逻辑

霍尔木兹收费、封锁、水雷和通航扰动仍会影响油价、通胀和全球风险偏好。光伏设备出口限制则会影响海外订单和设备公司估值。

#### 公司逻辑

正泰电源受韩国光伏计划和海外光储需求刺激，但能源替代逻辑可能受地缘缓和影响。光伏设备出口限制需要看政策和公司订单。

#### 交易逻辑

能源和光伏设备更多是事件驱动或风险验证，不应替代 AI 硬件主线。

## 待验证问题

1. 协创数据与超微系统、高端 Nvidia 服务器采购是否有公告、合同、海关或权威报道支持。
2. 宏景科技、协创数据、利通电子、盈峰环境的真实拿卡渠道、合同金额、交付节奏、融资成本和收入确认方式。
3. 算力租赁公司是否已与模型公司签署 Token 分成或合建分成协议。
4. Lumentum 产能排期、光芯片涨价和国内厂商导入北美 CSP 的真实性。
5. 韩国光伏装机目标、正泰电源韩国份额、美国工商业光伏和海外大储订单是否兑现。
6. 光伏设备对美出口限制是否有正式政策文件或公司订单延期证据。
7. 霍尔木兹通行费、加密货币支付和封锁/水雷相关信息是否有权威来源确认。

## 风险提示与通俗解释

- **卡源合规风险**：如果高端卡来源不稳定或监管加强，算力租赁公司的交付、融资和客户合作都会受影响。
- **模式验证风险**：Token 分成能提高想象空间，但如果没有合同和收入确认，就仍是叙事。
- **高位抱团风险**：光芯片和算力租赁都已有明显涨幅，趋势破位后回撤可能很快。
- **宏观反复风险**：霍尔木兹事件若再升级，会重新压制风险偏好和成长股估值。
