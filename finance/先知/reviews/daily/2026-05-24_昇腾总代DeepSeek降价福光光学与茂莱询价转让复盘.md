## 核心观点

1. **DeepSeek API 永久降价被解释为利好底层算力需求。**
   - 作者认为这只是把此前 2.5 折优惠转为永久定价。
   - 降价本质上推动模型从少数客户试用进入高频调用普及，带动 Token 消费扩张。
   - Token 消费扩张再推动推理算力需求，形成国产算力供需放量逻辑。

2. **昇腾伙伴大会强化总经销模式。**
   - 成员转述天风计算机团队总结，称华为 PAE 聚焦钻石和金牌伙伴，培养 2 家总经销商面向银牌及以下伙伴提供支撑。
   - 截图显示总经销商承担产品供应、技术支持、开放实验室和降低客户技术门槛等功能。
   - 深圳华强、神州数码被反复指向昇腾计算部件总经销线索。

3. **海外高端算力租赁和国产算力放量被区分节奏。**
   - 作者回应“昇腾放量是否冲击现有算力租赁龙头”时，认为海外高端算力租赁短中期逻辑与 AIDC 国产算力放量中长期逻辑不冲突。
   - 当前算力租赁高位仍看趋势，但不能忽视国产算力替代的中长期变化。

4. **福光股份补充半导体检测光学线索。**
   - 原文称股东大会重要内容包括半导体检测/工业视觉光学已量产并贡献营收。
   - 产品包括亚微米级显微镜头、连续变焦显微系统、双远心工业镜头、高精度线扫镜头。
   - 战略上强调不分红、投入半导体光学研发和产线扩产，目标成熟制程 DUV 光学部件国产替代，并储备 ArF、EUV 光学技术。

5. **茂莱询价转让被解释为短期扰动与扩产融资。**
   - 作者称需认真看公告，直接转让对股价有影响但不走二级市场。
   - 转让原因被解释为支持业务发展、产能建设、长期战略布局及自身资金需求。
   - 作者进一步称机构交流印证“老板减持把钱借给上市公司加速拿地扩产”的说法，但该部分是圈内转述，必须待公告和财务证据验证。
   - 作者同时提醒新同学，这不是新机会提示，而是自 2024 年 10 月以来持续跟踪的光刻机板块龙头，没先手成本优势更要学会波段和等待分歧。

## 主线拆解

### 主线一：DeepSeek 降价与国产算力需求

#### 行业逻辑

模型 API 降价会压低单 Token 价格，但如果大幅提升调用频次和用户覆盖，可能扩大总 Token 消费。作者把它理解为“价格拐点推动普及”，进而增加推理算力需求。

#### 公司逻辑

该逻辑影响国产算力链、昇腾生态、算力租赁和 Token 工厂，但不同公司受益路径不同：芯片和服务器看出货，AIDC 看上架和客户，Token 工厂看调用量、定价、分成和毛利率。

#### 交易逻辑

降价不是单向利好。若调用量增速超过价格降幅，底层算力需求受益；若只压缩单价和毛利，Token 工厂利润可能受压。

### 主线二：昇腾总经销模式

#### 行业逻辑

昇腾生态从整机、板卡、单卡到开发支持逐步复杂，若出货扩大，总代可以承担库存、渠道、技术赋能和下游伙伴支撑。

#### 公司逻辑

深圳华强和神州数码被反复作为总经销线索，但必须验证是否为正式授权、授权范围是芯片/板卡/整机/计算部件中的哪一类，收入确认和毛利率如何。

#### 交易逻辑

分销模式空间可能大，但毛利率不一定高。高位主题交易时，应防止把“总代资格”直接外推为高利润。

### 主线三：福光与茂莱的光学链

#### 行业逻辑

半导体检测、工业视觉、光刻机光学和光通信都在提升光学系统要求，具备精密加工、显微镜头、远心镜头、线扫镜头、光刻光学能力的公司进入验证池。

#### 公司逻辑

福光股份看半导体检测镜头量产、DUV 光学部件国产替代和产线扩产；茂莱光学看光刻机、半导体量检测、CPO/OCS/FSO、北美客户和产能扩张。

#### 交易逻辑

茂莱询价转让属于短期交易扰动。若公告用途和资金流向支持产能建设，长期逻辑不一定改变；但减持、估值提前反映和高位波动仍需纳入风险。

## 待验证问题

1. DeepSeek API 永久降价的官方价格、适用模型、计费方式和实际调用量变化。
2. 降价后 Token 消费是否显著增长，是否真正传导到国产算力、AIDC 和 Token 工厂收入。
3. 昇腾伙伴大会中总经销模式的官方文件、伙伴名单、授权范围和职责边界。
4. 深圳华强、神州数码是否被正式授权为华为计算部件或昇腾相关总经销商。
5. 总经销业务对应芯片、板卡、整机、开放实验室服务还是技术支持，收入和毛利率如何确认。
6. 昇腾 950 出货、下游需求和闲置率改善是否有客户、招标或财报验证。
7. 福光股份股东大会转述的半导体检测/工业视觉光学产品是否已有量产收入和客户。
8. 福光股份 DUV、ArF、EUV 光学部件储备是否有研发、客户验证和订单证据。
9. 茂莱光学询价转让主体、规模、定价、受让方和资金用途是否与作者解释一致。
10. 茂莱光学是否存在“老板借款给上市公司加速拿地扩产”的公告、借款协议、关联交易或财务记录。
11. 茂莱半导体在手订单、光通信新增订单、产能瓶颈和泰国产能是否能被公告或 IR 验证。
12. 算力租赁高位趋势是否继续维持，国产算力放量对传统高端卡租赁是否产生价格和客户结构冲击。

## 风险提示与通俗解释

- **降价双刃剑风险**：API 降价可能扩大调用，也可能压低单位收入，需要看调用量能否放大。
- **授权边界风险**：总经销、伙伴、开放实验室和技术支持不是同一概念，不能直接等同于高利润订单。
- **分销资金风险**：总代模式可能需要库存和账期，占用资金并带来价格波动风险。
- **股东转让风险**：询价转让即便不走二级市场，也会影响短期情绪和估值。
- **圈内转述风险**：资金用途、机构交流和客户订单必须以公告和财务资料为准。
- **先手风险**：作者明确提醒茂莱是长期跟踪后的阶段性上涨，没有先手成本优势时更要等待分歧。
