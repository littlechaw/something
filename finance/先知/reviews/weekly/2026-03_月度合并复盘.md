# 2026-03 先知月度复盘

## 阅读结论

2026 年 3 月的核心不是单一题材轮动，而是 **地缘冲突反复压制风险偏好，AI 算力主线在波动中继续扩散**。主线从最初的国产算力、先进制程，逐步扩展到 **超节点互联、先进封测、第三方测试、光通信上游、AI Agent 基础设施、AIDC、储能能源替代和自主可控光刻机链**。

本月最重要的投资脉络可以概括为：

1. **宏观扰动提供分歧窗口**：美伊冲突、霍尔木兹、油价和美元扰动反复压制成长股，但作者反复强调这类冲击更多改变节奏，不直接推翻 AI 算力和半导体主线。
2. **AI 算力从芯片扩散到系统工程**：市场关注点从单卡、缺卡，扩展到超节点互联、交换芯片、连接器、封装、测试、AIDC 和电力配套。
3. **Token 调用量和云涨价成为基本面验证信号**：阿里云 AI 算力和存储涨价，被视为 Token 消耗放大、算力供需紧张向价格传导的证据。
4. **半导体“卖铲人”优先级上升**：先进制程扩产、存储扩产、国产替代共同指向设备、材料、零部件、测试、探针、光学和光刻机供应链。
5. **储能是地缘风险下的阶段性机会**：欧洲和中东能源安全压力带来户储、大储、逆变器和电网设备订单线索，但持续性弱于 AI 主线，需要看订单和业绩。
6. **高位必须看交易纪律**：本月多次强调 5 日线、10 日线、量化兑现、涨幅过大后的回撤风险，不应把长期逻辑直接等同于短线持有理由。

## 时间脉络

### 3 月上旬：地缘冲击下，AI 主线被重新筛选

3 月初，美伊冲突、油价、美元和全球流动性扰动成为市场主导变量。作者的处理框架是：**外部冲突影响节奏，不替代产业主线**。

当时重点强调：

- AI、国产算力、先进制程和先进封测仍是中长期主线。
- 户储、油气、能源替代属于冲突催化下的阶段性窗口。
- 如果市场因外部冲击调整，应优先观察强主线是否出现错杀，而不是追逐纯避险题材。
- 高位标的一旦跌破 5 日线/10 日线且不能修复，必须按交易纪律处理。

这一阶段的主线关键词是：**国产算力、先进制程、先进封测、测试链、昇腾链、液冷、户储避险**。

### 3 月 5 日至 3 月中旬：国产算力向超节点和 Agent 基础设施扩散

随后，国产算力主线从芯片本身扩展到系统工程。作者提出一个关键判断：**国产超节点不是只贵在芯片，更贵在通信互联**。

新增重点包括：

- **交换芯片**：盛科通信被反复提及，逻辑是超节点和大规模集群需要更强网络侧能力。
- **连接器**：华丰科技、意华股份等对应背板高速连接器、IO 连接器和跨柜互联。
- **第三方测试**：伟测科技、利扬芯片等从传统周期环节，被重新定位为先进制程良率配套和国产 GPU 流片回流承接方。
- **AI Agent 基础设施**：OpenClaw/AutoClaw 带动对向量数据库、智能 APM、边缘计算/CDN 的讨论。

这一阶段的核心变化是：**AI 不是只买 GPU 或服务器，而是带动数据、网络、测试、封装、边缘节点和软件基础设施一起扩张**。

### 3 月中下旬：云涨价、测试通胀和光芯片供需成为验证信号

3 月 17 日至 18 日，阿里云 AI 算力和存储涨价成为本月最重要的验证事件之一。作者将其解释为：**Token 调用量高增长开始通过云厂涨价、资源倾斜和算力供需紧张传导到基本面**。

本阶段三条线同时加强：

| 方向 | 核心逻辑 | 关注点 |
| --- | --- | --- |
| Token/云涨价 | AI 调用量提升，云厂 AI 算力、存储价格上涨 | 云厂价格表、MaaS、API 调用量、毛利率 |
| 测试链量价通胀 | AI 芯片测试时间变长、测试设备升级、探针耗材价值量提升 | 和林微纳、伟测科技、长川科技、精智达、金海通、矽电股份 |
| 光芯片/CPO | Lumentum 等海外光通信上游供需紧张，国内导入机会增加 | 源杰科技、仕佳光子、长光华芯、永鼎股份、云岭光电、设备端罗博特科/科瑞技术 |

这一阶段的主线更偏 **基本面验证**，比单纯概念发酵质量更高。

### 3 月下旬：储能、半导体材料设备和光通信材料扩散

3 月 20 日至 27 日，地缘冲突继续扰动市场，但主线开始扩散到四个方向：

- **储能能源替代**：逆变器出口、欧洲户储、中东能源安全和海外大储成为阶段性线索。
- **国产算力/AIDC**：AIDC、算力租赁、边缘云、云电脑、云手机等继续发酵。
- **光通信上游材料**：法拉第旋光片、硅光 Fab、卓胜微类 Tower 逻辑被讨论。
- **先进制程材料设备**：鼎龙股份业绩预告、洁美科技收购埃福思、江丰电子靶材、京仪装备、富创精密、珂玛科技等设备材料零部件被强化。

本阶段最清晰的基本面线索是 **鼎龙股份一季报预告**，半导体材料业务被视为从概念进入业绩验证。

### 3 月末至 4 月初：宏观事件映射增加，但主线仍回到订单和验证

3 月 31 日至 4 月初，美伊冲突、霍尔木兹通航、人民币能源结算、中油资本、商业航天发射失利等事件增多。

作者的处理方式比较克制：

- 储能订单改善可以继续跟踪，但要看德业、艾罗、固德威等 Q1/Q2 订单和排产。
- 国产算力和 AIDC 是冲突缓和后的科技修复核心。
- 光刻机 ArFi 订单如果被证实，催化等级较高；未证实时仍按事件传闻处理。
- 中油资本属于人民币石油结算事件映射，长期价值取决于昆仑银行真实业务贡献。
- 商业航天单次发射失败会冲击情绪，但产业趋势需看后续发射窗口和订单。

## 主要投资方向

### 1. 国产算力、AIDC 与超节点

这是三月最核心方向。逻辑从“国产 AI 芯片供给不足”升级为 **国产算力系统化建设**。

| 细分方向 | 代表线索 | 核心验证点 |
| --- | --- | --- |
| AIDC/算力租赁 | 科华数据、利通电子、东方国信、森远股份、奥瑞德 | 客户合同、机柜交付、算力租赁价格、收入确认 |
| 昇腾链 | 华丰科技、意华股份、申菱环境 | 昇腾订单、超节点价值量、液冷供应份额 |
| 交换芯片 | 盛科通信 | 大厂 scale out/scale up 导入、客户认证、订单 |
| 连接器 | 华丰科技、意华股份、航天电器 | 950 线模组、224G 背板连接器、小批量和规模供货 |
| 边缘云/CDN | 网宿科技 | AI 边缘计算收入、云厂合作、价格传导 |

阅读要点：**三月不是简单炒“算力”，而是在寻找国产算力放量后最紧、价值量提升最快、证据逐步变密的环节。**

### 2. 先进制程、先进封测与测试链

这一方向贯穿全月，逻辑是 **先进制程扩产会向封装、测试、设备、材料、零部件持续传导**。

| 环节 | 代表标的/方向 | 核心逻辑 |
| --- | --- | --- |
| 第三方测试 | 伟测科技、利扬芯片 | 国产 GPU 回国流片、封测分离、测试外包增加 |
| 测试设备 | 长川科技、精智达 | AI 芯片测试复杂度提升，设备 ASP 和需求提升 |
| 分选/探针/耗材 | 金海通、和林微纳、强一股份、矽电股份 | 测试时长、Pin 脚、功率和精度要求提升 |
| 先进封装 | 盛合晶微、甬矽电子、长电科技、通富微电 | CoWoS、HBM、国产算力封装需求 |
| 半导体材料 | 鼎龙股份、江丰电子、欧莱新材 | 抛光垫、抛光液、靶材涨价和国产替代 |
| 设备零部件 | 富创精密、京仪装备、珂玛科技、骄成超声 | 存储扩产、先进逻辑扩产、国产设备链订单 |

本月最值得沉淀的判断是：**测试链不是低壁垒周期尾部环节，而是先进制程、AI 大芯片和国产算力良率的关键瓶颈。**

### 3. AI Agent、Token 与软件基础设施

三月的 Agent 线并不是单纯炒应用，而是围绕 **Agent 普及导致 Token 消耗非线性增长** 展开。

| 方向 | 逻辑 | 代表线索 |
| --- | --- | --- |
| 云涨价 | Token 调用量增长，云厂 AI 算力和存储涨价 | 阿里云 AI 算力/存储涨价 |
| 向量数据库 | Agent 需要长期记忆、低延迟检索和实时向量化 | 星环科技、海量数据 |
| 智能 APM | Agent 调用链复杂，需要预算感知、链路追踪、成本控制 | 博睿数据 |
| 边缘计算/CDN | 高频工具调用带来低延迟和网络加速需求 | 网宿科技 |
| 安全合规 | Agent 风险提示促使大厂沙箱、隔离、合规化 | 网安、CDN、云安全相关方向 |

核心判断：**Agent 安全风险会打击纯概念情绪，但不证伪 AI Agent 普及和 Token 消耗增长趋势。**

### 4. 光通信、光芯片、硅光与上游材料

本月光通信方向从光模块扩展到更上游的光芯片、材料和硅光代工。

| 分支 | 核心逻辑 | 需要验证 |
| --- | --- | --- |
| 光芯片/CPO | EML、CW、UHP、InP 等供需紧张，海外供给不足给国产导入机会 | 客户、订单、产能、价格 |
| 法拉第旋光片 | Granopt 停炉传闻带来供给冲击和国产替代想象 | 停炉真实性、库存、重启周期、国产认证 |
| 硅光 Fab | 卓胜微、燕东微等被讨论为硅光代工平台 | SOI/SiGe 工艺能力、硅光订单、收入分项 |
| 光刻机光学 | 茂莱光学、汇成真空、波长光电等受事件催化 | 供应链关系、订单、收入占比 |

处理原则：**光通信上游弹性大，但不少线索证据链较弱，适合重点核验，不适合只靠想象追高。**

### 5. 储能与能源替代

储能是三月宏观冲突下的重要阶段性方向。它的逻辑来自欧洲和中东能源安全压力、天然气价格波动、户储订单改善、海外大储和电网设备出海。

| 标的/方向 | 关注点 |
| --- | --- |
| 德业股份 | 欧洲/中东户储订单、区域收入、工商储利润 |
| 艾罗能源 | 欧洲户储、工商储订单、费用率和利润拐点 |
| 固德威 | 澳洲/欧洲出货、储能电池收入 |
| 正泰电源 | 北美光储、韩国市场、数据中心储能 |
| 鹏辉能源 | 户储小电芯供给紧张、价格和订单 |
| 锦浪科技 | 户储、工商储、电池包和大储布局 |

核心判断：**储能是事件催化与订单兑现结合的方向，但持续性取决于订单、排产和利润，不应只看地缘新闻。**

### 6. 光刻机、自主可控与人民币结算事件

三月后半段，光刻机链、人民币能源结算和商业航天都出现过较强事件催化。

| 事件方向 | 投资属性 | 处理方式 |
| --- | --- | --- |
| 国产光刻机 | I 线、KrF、ArFi、EUV 镀膜等传闻和订单线索 | 按事件催化处理，优先核验招投标和供应链公告 |
| 中油资本/昆仑银行 | 人民币石油结算映射 | 关注官方政策、银行业务披露、实际利润贡献 |
| 商业航天 | 天龙三号首飞失利、蓝箭 IPO 中止 | 高催化高波动，跟踪后续发射和审核恢复 |

核心判断：**这些方向短线弹性来自事件，但中长期价值必须回到公告、订单和业务贡献。**

## 本月交易纪律

1. **主线再强，也要区分低位逻辑变化和高位趋势交易。**
2. **高位标的不能只靠长期逻辑硬扛，5 日线/10 日线是短线纪律线。**
3. **传闻线索先做验证，不直接当事实。**
4. **宏观冲突导致的急跌，优先观察强主线是否错杀；宏观缓和后的反弹，优先看谁能率先修复。**
5. **储能、人民币结算、商业航天等事件线，要看催化是否能转化为订单、收入或利润。**
6. **真正值得持续跟踪的是证据越来越密的方向：云涨价、测试通胀、半导体材料业绩、AIDC 订单、超节点互联导入。**

## 当前处理结论

三月可以沉淀为一个清晰框架：**宏观冲突制造波动，AI 算力和半导体主线继续扩散，真正值得跟踪的是从叙事走向订单、价格、财报和客户验证的环节**。

后续阅读这些资料时，不应把三月看成很多零散题材，而应看成一条主线的展开：

**Token 消耗增加 → 云涨价和算力紧缺 → 国产算力/AIDC 扩张 → 超节点互联、封装、测试、设备材料、光通信上游同步受益 → 用订单、价格和财报验证真伪。**
