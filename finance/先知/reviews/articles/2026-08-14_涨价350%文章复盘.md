# 2026-08-14 《涨价，350%！！！》文章复盘

- 日期：2026-08-14
- 来源：公众号文章
- 文章标题：涨价，350%！！！
- 相关主题：晶圆代工涨价、成熟制程、先进制程、国产算力、DeepSeek API 定价、半导体设备材料
- 涉及行业：晶圆制造、AI 芯片、国产 GPU、半导体设备、零部件、材料、模型 API
- 涉及标的：中芯国际、华虹公司、晶合集成、燕东微、华润微、芯联集成、半导体设备材料链、DeepSeek、字节、阿里、腾讯

## 一句话结论

文章试图用中芯国际、华虹公司二季度业绩和 DeepSeek API 涨价，证明 AI 需求正从先进制程向成熟制程、晶圆代工、设备材料和国产算力全链条传导；其中财报超指引和毛利率改善是较强的验证线索，但国产 GPU 出货、云厂资本开支、全球成熟制程减产和 API 涨价带来的产业链利润传导仍需要逐层确认。

## 文章核心观点

1. **晶圆代工二季度出现量价和利润率共振。**
   - 文章转述中芯国际 26Q2 营收约 30 亿元、环比增长约 20%，毛利率 25.3%，稼动率 93.7%；26Q3 指引为营收环比增长 2%-4%、毛利率 26%-28%。
   - 文章转述华虹宏力 26Q2 营收约 7.18 亿元、环比增长 8.6%，毛利率 16.5%，稼动率 102.8%；26Q3 指引为营收环比增长 7%-8%、毛利率 16%-18%。
   - 作者据此判断，订单超过产能、提价和产能瓶颈开始转化为利润，而不只是营收和市场份额增长。

2. **华虹的涨价和产能约束被视为短期弹性更强的环节。**
   - 文章称部分产品订单达到可用产能的 1.5-2.0 倍，多个产品平台已经提价，2H26 至 2027 年仍可能继续提价。
   - 第二座 12 英寸厂的新增产能主要在 Q4 和 2027 年体现，第三座无锡 12 英寸厂于 Q3 搬入设备、后续持续爬坡，因此短期供给约束仍在。

3. **先进制程和成熟制程被拆成两条 AI 需求链。**
   - 先进制程主要承载 GPU、ASIC、XPU、数据中心 CPU、部分 DPU 和高端交换芯片等主芯片。
   - 成熟制程主要承载 PMIC/BCD、电源器件、BMC、MCU、时钟、传感器、接口芯片及部分光通信配套芯片。
   - 作者的核心判断是：AI 从单芯片竞争走向整柜和超节点竞争后，成熟制程的电源、控制和互联配套价值量上升，先进与成熟制程将同步受益。

4. **国产算力被放在晶圆代工景气的需求端。**
   - 文章将产业链描述为“大模型发展→国产算力设计公司订单上修→先进制程紧缺→产能建设释放→设备零部件和国产算力供需共振”。
   - 中芯国际、华虹公司代表先进与成熟制程；晶合集成、燕东微、华润微、芯联集成等被列为成熟/特色工艺的补充受益方向。

5. **DeepSeek API 涨价被解读为需求和商业化拐点。**
   - 文章称 DeepSeek 将百万 Tokens 输出价格上调 125%-350%，作者据此判断算力供给紧张、模型需求旺盛，开源模型正在从极致低价转向更正常的商业化定价。
   - 进一步推演认为，API 收入和毛利率改善可能为模型公司后续购买算力提供资金，并缓解市场对国产模型价格战的担忧。

6. **云厂资本开支和国产化倾斜是需求侧的远期催化。**
   - 文章预计字节、阿里、腾讯等国产云厂商 2027 年资本开支仍保持 60%-70%以上增长，并认为国模、国芯生态已经落地。
   - 这一部分是作者的远期判断，不能用来替代云厂正式 CapEx、采购结构和供应商订单数据。

## 论证链条

1. AI 主芯片和配套芯片需求增加，先进制程与成熟制程同步消耗产能。
2. 海外晶圆厂将资源向先进制程、先进封装和高毛利 AI 产品倾斜，成熟制程供给收缩。
3. 订单外溢至大陆晶圆厂，推动稼动率、ASP 和毛利率改善。
4. 国产 GPU 量产后，国内先进制程和成熟配套芯片需求进一步增强。
5. 晶圆厂扩产传导至设备、零部件、材料和下游国产算力供应链。

## 交易与风险表达

- **文章最有价值的部分是把晶圆代工从“营收增长”推进到“毛利率和价格兑现”观察。** 后续应优先看正式财报、ASP、稼动率、合同负债和资本开支，而不是继续线性外推远期涨价。
- **先进与成熟制程的分层有研究价值，但并不意味着所有晶圆厂或所有产品同步涨价。** 产品结构、客户议价能力和产线折旧差异会导致利润弹性分化。
- **国产 GPU 量产是关键状态跳变，但文章没有给出可追溯的客户、出货、产能和收入证据。** 需要把芯片出货、晶圆投片、封装测试和服务器交付拆开跟踪。
- **DeepSeek API 涨价不能直接等同于算力需求增加。** 还要观察涨价后的调用量、客户留存、单位推理成本和模型公司的现金流。
- **高位交易纪律仍然适用。** 晶圆代工、设备材料和国产算力若已提前反映涨价预期，应等待财报和订单验证，不能只用行业空间或远期市值测算追涨。
