### 三、存储涨价叙事松动（核心干货）

#### NAND 闪存谈判折价

> 头部闪存厂跟云服务厂商谈长期供货协议，**折价近 25%**，而且是对初始报价的折价，不是对即期价的折价。

| 结论 | 详细 |
|------|------|
| **NAND 议价权弱** | 为了签长期协议，常规折扣不好使，要加大力度 |
| **DRAM 议价权强** | 下游没有这种博弈空间 |
| **存储涨价叙事根基动摇** | 不颠覆逻辑，但"一丝怀疑就够了" |

#### AI 服务器存储用量的"话术"

| 说出来的 | 没说出来的 |
|----------|------------|
| AI 服务器存储用量是传统 4-5 倍 ✅ | DRAM 是 8-10 倍 |
| | NAND 被稀释了 |

> 闪存大会上把 DRAM 和 NAND 混在一起说，不敢单独拆——因为 NAND 增量根本没那么大。

#### 近三个月 NAND 现状

```
现货：疲软阴跌
合约价：涨幅持续收窄
             ↓
    分化严重：DRAM > NAND > 模组厂 > 小厂
```

#### 相关公司定位

| 类型 | 公司 |
|------|------|
| 规模原厂 | 长江存储（未上市） |
| 模组厂 | 江波龙 |
| 原厂小厂 | 大普微 |
| 介于模组厂和原厂之间 | 群联电子 |

> NAND 真正的"诗和远方"是**端侧 AI**，但端侧 AI 还没整体起来，NAND 只能先把溢价的估值挤一挤。

#### DRAM 共振调整

> DRAM 本没问题，但前期交易过度拥挤，NAND 松动 → 一丝怀疑 → DRAM 跟着出逃。**共振调整，必然发生。**

## 格兰投研

### 一、今天为什么跌？不是小作文那么简单

#### 真正的原因：美国科技股 CDS 拉响警报

| 概念 | 解释 |
|------|------|
| **CDS** | 债券的"违约保险"，越高=市场越不信任 |

```
甲骨文 Oracle：
  年初 CDS：144 基点 → 现在 215 基点（涨近 50%）

英伟达、Alphabet 等 CDS 同时创历史新高
```

#### 为什么偏偏现在拉警报？

```
                      年初预测          7月预测
五巨头年资本开支       4850 亿美元  →   7300 亿美元

明年：
  资本开支增加  +5340 亿
  经营现金流    +3400 亿
              ↓
  每增加 1 美元现金流，要花 1.57 美元资本开支
```

> **科技公司越来越像重资产、高资本开支、依赖外部融资的数据中心运营商。** 当资本开支超过现金流增长，市场自然追问：回报在哪？谁兜底？

### 二、英伟达的"循环融资"闭环（顺时正循环，逆时反噬）

```
顺时：
  英伟达提供资金 → AI 公司采购英伟达 GPU → 英伟达获得订单 → 股价涨
                                ↓
                    像永动机

逆时（现在）：
  AI 公司收入预期下降 → 买算力能力减弱 → 芯片订单减少
         ↓
  芯片公司继续提供资金 → 自身财务压力加大 → CDS 飙升
         ↓
              "两级反转了属于是"
```

### 三、我们这边怎么看——国产 DUV 光刻机

#### 对 ASML 的影响

| 媒体说的 | 实际情况 |
|----------|----------|
| 国产 DUV 交付=颠覆格局 | ✅ 迈出重要一步，从研发走向交付 |
| 马上替代 ASML | ❌ 差得远 |

#### 四个阶段，我们在第一阶段

```
1. 完成制造 → 能曝光晶圆（我们现在在这）
   ↓
2. 交付客户 → 进入晶圆厂测试
   ↓
3. 工艺验证+可靠性验证+稳定性验证
   ↓
4. 批量采购→稳定参与大规模生产
```

> "设备能曝光晶圆，只说明它'可以工作'。连续、稳定、高效率曝光，才说明具备量产价值。"

#### 不要高估当前水平

| 对比 |
|------|
| ASML：2008 年发布 1950i → 2015 年推出 1980Di，**用了 7 年** |
| 国产：解决的是从实验室进晶圆厂的问题 |

> 大概率没法直接对标 ASML 1980Di。"能对标甚至超过才有问题。"
