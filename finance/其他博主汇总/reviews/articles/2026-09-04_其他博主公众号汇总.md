## 格兰投研

**核心总结：**

A股当日**高开低走**，在外围市场全面上涨的背景下走出独立下跌行情。作者认为下跌根源不在外部利空，而在**场内资金人心涣散、互相抢跑**；当前市场处于资金周期的低参与阶段，需等待**缩量止跌**与**放量确认**两个右侧信号。文末解读8月非农数据，认为就业市场"没有明显坏掉"但**并未过热**，温和就业叠加温和通胀的预期对黄金构成支撑。

**一、盘面与外围反差**

| 市场 表现    |             |
| -------- | ----------- |
| 隔夜美股（纳指） | 涨1.4%，科技股大涨 |
| 日经指数     | 涨1.3%       |
| 韩国KOSPI  | 涨1.6%       |
| A股       | 高开低走，独立下跌   |

外围利好因素包括：美联储理事沃勒释放**不加息**信号、美债收益率回落。

**二、下跌归因分析**

1. **小作文因素不成立**：关于大人物去世的传闻火速被证伪，且美元、美债、黄金、美股期货全天平稳。
2. **AI巨头集体宕机不构成算力利空**：ChatGPT、Claude、Grok几乎同时宕机，各家解释为路由错误、计算中心故障、基础设施故障。此事反而强化**算力冗余、多供应商**的产业价值；韩国半导体、日本AI资产照涨，全球资金未将其视为算力利空，唯独A股算力硬件集体下跌。强行从新闻找下跌原因属于"给市场圆故事"。

**三、真正病根：资金面**

- **当日放量2700多亿发生在冲高回落中**：上涨放量说明有人愿以更高价接筹；下跌放量说明套牢筹码松动、有人扛不住。
- 演变链条：**高开—兑现—承接不足—调整—筹码进一步松动**。
- 资金无聚焦：当日领涨的是农业、鸡鸭鱼肉、白酒等低位板块，本质是**存量资金不足**，只能寻找"位置更低、筹码更干净、当天有催化"的方向轮动。
- 当前阶段特征：**低风险偏好、低换手率、低参与意愿**，并非一致性看空。

**四、量能周期规律**

历史数据（过滤短期噪声后）显示A股存在**15—20周左右的量能周期**：

1. 数周放量、活跃度上升
2. 进入高位量能平台
3. 赚钱效应下降后缩量调整

需确认的两个右侧信号：

- **缩量止跌**：抛压衰竭，应提高关注度，但还不是最舒适的进攻阶段
- **放量确认**：如成交从1.8万亿回升至**2万亿、2.2万亿**，且**连续多日**维持更高平台（非单日放量），市场性质才真正转变，资金从"观望"转为"参与"

**五、8月非农数据解读**

- 新增就业**16.2万人**，远超预期的5.3万人，表面强劲但**质量不高**：&#x20;
  - 餐饮业新增5.9万、地方政府教育新增4.2万，两行业合计**占六成以上**
  - 信息业减少2.3万、金融业减少1.1万，并非全面升温
- 近三个月平均新增约**7.1万人**，仅证明就业市场**没有明显坏掉**，不足以证明全面过热。
- 交易含义：非农大超预期**未必导致黄金持续大跌**。
- 后续关注8月CPI与议息会议：若核心CPI继续回落，则形成**温和就业+温和通胀**的组合，美联储没有急迫加息必要，这是黄金真正等待的环境。
