## 主波浪

### 核心观点：缩量≠恶化，市场正在"止血"

作者开篇承认这周很折腾人，但提醒读者：
- 同样缩量，过去 10 天是**一路调整、流动性危机**
- 今天缩量 4500 亿，但**指数稳住了、核心方向没有继续恐慌**

**变化虽小，但方向不一样了。**

### 一、情绪修复需要时间

> "就像夫妻吵架十天，第十一天说和好，也不可能马上回到以前。"

市场情绪的恢复路径：**恐慌 → 冷静 → 重建信心**，这是过程。

现阶段最忌讳的是**着急**，一着急就容易亲手浇灭希望。

### 二、硬件产业逻辑未变

| 信号 | 内容 |
|------|------|
| **谷歌** | 财报公布，再次提高全年资本开支预期 |
| **OpenAI** | 数据中心投资计划进一步上调 |

作者判断：**真正有成长的方向，资金还在持续投入，硬件产业逻辑没有因这周调整而改变。**

> 不看一天两天涨跌，看产业趋势还在不在。趋势没变，震荡就只是震荡。

### 三、关于长鑫上市的担忧

- 这是**个人控制不了的事**
- 也**无法证明**长鑫上市 → 科技一定涨/跌
- 担心就回避，明天还有时间
- 想在不确定的事上找确定性，本身就不现实

> 不论长鑫上市与否，不影响科技整体逻辑。短期或许虹吸，但那只是短炒的人需要在意的事。

### 四、结尾：互相打气

作者理解大家心态脆弱，状态不好别闷着，留言区互相加油。

### 一句话总结

> 缩量但指数企稳，市场从"恶化"切换到"止血"阶段。产业逻辑（AI 硬件）未变，情绪恢复需要时间，别着急。长鑫上市是噪音，不影响大局。

## 格兰投研

### 一、谷歌财报：AI 业绩验证第一枪，过关

| 指标 | 数据 |
|------|------|
| 营收 | 1197.96 亿美元，同比 +24% |
| 营业利润 | 407.70 亿美元，同比 +30% |
| 营业利润率 | 34%（去年 32%） |
| 谷歌云 Q2 收入 | 247.68 亿美元，环比 +24% |
| 订单积压 | 超 5000 亿美元 |
| 上半年资本开支 | 806 亿美元 |
| 下半年预计 | 约 1194 亿美元（每季度 ~597 亿，比 Q2 的 449 亿高 33%） |

### 二、大摩观点：AI 军备竞赛仍在加速

| 时间节点 | 五大巨头资本开支预期 |
|----------|---------------------|
| 明年 | **1.2 万亿美元** |
| 2028 年 | **1.4 万亿美元** |

> 作者与大摩朋友交流确认：全球科技巨头 AI 资本竞赛继续加速，且仍有进一步上调空间。

**核心逻辑变化**：不再是"买芯片"的逻辑，而是**抢电力、抢土地、抢机房、抢供应链、抢建设时间**——为 2027-2029 年的新一代芯片提前布局基础设施。

### 三、市场最大分歧：钱花出去了，收入能回来吗？

算力变现链条能否跑通，取决于七个环节：

```
数据中心建成 → 芯片交付 → 算力上线 → 客户订单增加
→ 算力利用率高位 → 未交付订单确认收入 → 收入覆盖折旧/电力/建设成本
```

只要这个链条顺畅，万亿资本开支就能转化为未来数年的云收入，AI 最大的疑虑就烟消云散。

**当前状态**：海外 AI 产业链尚未完全过关，还有英特尔、微软、Meta、AMD、亚马逊等财报等待验证。

### 四、DeepSeek 梁文锋会议解读

**核心一句话**：DeepSeek 不做互联网平台，要成为专注 **AGI 基础研究**的公司。

**关键判断**：
- 当前最重要的产品方向是 **Coding Agent**（编码智能体）
- 技术路线：语言模型 → 思维链 → Agent → 持续学习 → AI 自我迭代 → 具身智能
- 当前 AI 最大问题：**不能真正持续学习**

**算力纠偏**（针对市场误读）：
- 梁文锋本意是"相同算力产出更多智能"，不是强调成本
- 低价对算力产业**不是坏事**：单次调用成本下降 → 调用量指数增长 → Token 总量增长
- 真正承压的：高价格、低效率、技术封闭的超高利润模式
- 算力投资逻辑转变：从"卡越贵越好" → **"谁能以更低成本生产更多 Token"**
- 国产算力的**超节点**逻辑仍可关注

### 六、防守方向：黄金/有色

### 七、投资哲学

> **富在术数，不在劳身；利在势居，不在力耕。**

市场大收益来自对**产业趋势、市场周期、资金方向**的判断，而非频繁操作。越勤奋交易，越被市场收拾。

### 一句话总结

> 谷歌财报过关、AI 资本竞赛加速、算力逻辑从"买贵卡"转向"低成本量产 Token"。长鑫上市前科技需压节奏、换筹码，上市后才能冲刺。黄金有色是防守方向。真正的收益靠判断趋势，不靠勤奋交易。
